# 📚 Estudos de HTML5 — Primeiro Projeto

## 🎯 Sobre o aprendizado

Neste projeto, comecei a aprender os fundamentos do HTML5 e como ele é utilizado para estruturar páginas web. Durante as atividades, pratiquei o uso de diferentes tags e compreendi como cada elemento contribui para a organização e apresentação do conteúdo de um site.

## 📝 O que aprendi

- **Estrutura básica do HTML:** aprendi a utilizar `DOCTYPE`, `html`, `head` e `body` para construir uma página web.
- **Títulos e parágrafos:** pratiquei as tags `h1` até `h6` e `p` para organizar textos e informações.
- **Listas:** conheci as listas ordenadas (`ol`) e não ordenadas (`ul`), utilizando `li` para representar seus itens.
- **Links:** aprendi a utilizar a tag `a` para criar links e permitir a navegação entre páginas.
- **Imagens:** conheci a tag `img` para inserir imagens no conteúdo.
- **Tabelas:** pratiquei o uso de `table`, `tr`, `th` e `td` para organizar informações em linhas e colunas.
- **Atributos HTML:** compreendi como atributos como `href`, `src`, `alt` e `lang` ajudam a configurar os elementos.
- **Organização do código:** aprendi a estruturar melhor o HTML, mantendo os elementos organizados e facilitando a leitura.

## 💻 Tecnologias e ferramentas

- HTML5
- Visual Studio Code
- GitHub para armazenar e compartilhar os códigos desenvolvidos.

## 🚀 Conclusão

Este projeto representa o início da minha jornada no desenvolvimento web. Com as atividades realizadas, pude compreender melhor a estrutura de uma página HTML e praticar os principais elementos utilizados na criação de sites. Esse aprendizado será a base para estudar CSS, JavaScript e desenvolver páginas cada vez mais completas.
